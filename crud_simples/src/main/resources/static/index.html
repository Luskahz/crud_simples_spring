Esta tela lista usuários de GET /usuarios e permite:

  • Excluir usuário DELETE /usuarios/{id}
  • Ver endereço/documentos
  • Criar usuário POST /usuarios
  • Criar endereço POST /enderecos
  • Criar documentos POST /documentos
  • Alterar senha PATCH /usuarios/alterarSenha/{id}
  • Gerar PDF usuários GET /usuarios/pdf
  • Gerar JSON documentos GET /documentos/json
  • Gerar CSV endereços GET /enderecos/csv
